# E 组总梯度投影贡献（纠正后的测量）

之前的独立 FP16 梯度测量未进行 loss scaling，出现明显数值误差。此前全模型梯度比例 48.8% 以及冲突批次数结论撤回。训练得到的权重、AP、遮挡误差及训练损失记录保持有效。旧 JSON 仅保留审计，已标记 SUPERSEDED。

本次所有分项使用共同的 loss scale 1024 后还原梯度。GT、坐标 KD（系数 0.04969）、余弦特征 KD（系数 0.1）和 CF（沿用原有内部权重）全部计入总梯度。使用 sum(g_i) 构造总梯度，以 FP64 累计 dot(g_i,g_total)/||g_total||²。每批、每组参数的分项贡献和均通过 100% 校验。

| 状态 | GT | 坐标 KD | 特征 KD | CF |
| --- | ---: | ---: | ---: | ---: |
| 重建的初始状态 | 88.1374% | 5.7382% | 6.1221% | 0.0024% |
| 第100轮原始参数 | 91.2887% | 6.5313% | 2.1835% | -0.0035% |

第100轮五批中，坐标 KD 和特征 KD 对总方向的投影均为正。两项合计平均约 8.71%。CF 平均为微小负值。
投影贡献描述当前梯度合成的几何关系，不能解释为准确率收益占比或 AdamW 最终参数更新占比。

## 校验与适用范围

使用同样五批 stage1 增强数据，每批 128 人，在本机 RTX 4060 Laptop、PyTorch 2.0.1+cu118 上执行，优化器更新次数为零。初始学生按 E 配置重建；第100轮从真实 checkpoint 的 ema_state_dict.module.* 读取原始学生参数。BatchNorm 缓冲区逐批恢复。
对比独立求导再相加与直接对总损失求导，十次测量的全模型相对差异为 0.234%–0.506%。残余差异来自混合精度数值计算。投影比例采用分项梯度相加定义的总梯度，逐批相加为100%。
以上是固定五批的局部诊断，早、中期权重缺失，本机环境也与5090训练环境有差异。所有梯度在裁剪、AdamW 动量、学习率及权重衰减变换之前测量。
