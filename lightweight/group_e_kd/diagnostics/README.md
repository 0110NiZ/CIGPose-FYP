# E 组梯度配对诊断

该报告在训练结束后，于本机 RTX 4060 Laptop、PyTorch 2.0.1+cu118 环境完成。用相同五批第一阶段增强图（每批 128 人），对比重建的初始学生与第 100 轮原始学生参数，测量 GT、加权坐标 KD、加权余弦特征 KD 及两项 KD 之和的梯度。所有参数和 BatchNorm 缓冲区经过恢复校验，优化器更新次数为零。

坐标 KD 系数为 0.04969，温度为 0.1；特征 KD 系数为 0.1。报告中的 kd_to_gt 为对应蒸馏梯度 L2 范数除以 GT 梯度 L2 范数。cosine 为两组梯度的方向余弦。combined_KD 表示两项加权蒸馏梯度相加后再比较 GT。summary 是五批指标的算术平均。

第 100 轮，坐标 KD 与特征 KD 的全模型梯度大小分别约为 GT 的 43.4% 和 23.1%，合并后为 48.8%。合并方向余弦平均为 0.063，五批中两批为负。特征 KD 的直接梯度作用于骨干和 CIM 前编码层，CIM、GNN 处为零。

这是一项固定输入的局部诊断。初始学生在本机重建，第 100 轮从实际 checkpoint 的 ema_state_dict.module.* 读取原始训练参数。早、中期 checkpoint 已被训练程序清理。本机软件版本与 5090 训练环境有差异，五批结果可用于提出后续实验，无法单独解释完整训练的因果关系。
