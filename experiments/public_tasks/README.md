## 数值验收边界

NPZ 保存/读取的数组逐位相同。相同特征在 GPU 上重复运算仍可能产生微小
float32 差异，argmax 解码可放大近似相等峰值的差异。先前严格检查曾观察到
0.03552246 原图像素的差异；最终 93 条复核记录了特征、坐标、分数的实际最大误差。
容差明确设为原图坐标 0.1 像素、分数 1e-5，Top-1 与 0.2 分数阈值判定要求不变。
详见 live_recheck.json 与 numerical_notes.json。这不是所有输入逐位一致的保证。
